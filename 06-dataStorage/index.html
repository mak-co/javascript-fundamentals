LocalStorage, SessionStorage and Cookies

LocalStorage

stores data in your browser which even closing the browser wouldn't lead to its deletion

SessionStorage

Its stores the data temporarily,but if you close the tab the data will get deleted

Cookies

It also stores data but it stores data of minimum storage(4kb) capacity as compare to local and session storage and those data saved as Cookies named property sent to server for future interactions or when page get reloded it get the data goes to the server
